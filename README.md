# Relógio Digital com Saudação

Um projeto simples em **JavaScript, HTML e CSS** que mostra a hora atual, uma saudação e altera a imagem conforme o período do dia.  

---

## Funcionalidades

- Mostra a hora atual (hora, minutos e segundos) atualizada a cada segundo.  
- Exibe uma saudação: **Bom Dia**, **Boa Tarde** ou **Boa Noite**, dependendo do horário.  
- Altera a imagem e a cor da saudação conforme a manhã, tarde ou noite.  
- Projeto leve e funcional, ideal para aprender a manipulação do DOM com JavaScript.

---

## Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (ES6)
